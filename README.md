# Метрострой

Браузерная стратегия о строительстве метро. Откройте `index.html` в браузере.

- Станции собирают пассажиров из домов в пешей доступности.
- Линии соединяют станции (через реку дороже).
- Вестибюли ускоряют вход и расширяют охват станции.
- Поезда и вагоны добавляются в карточке линии.
- Где метро не хватает, люди едут на машинах: пробки от 0 до 10 баллов.
- Рейтинг мэрии падает от пробок и давки; на нуле игра окончена.

Управление: колесо или щипок — масштаб, перетаскивание — сдвиг карты, 1–5 — инструменты, пробел — пауза, Esc — отмена.

## Яндекс Игры

Архив для загрузки собирается командой `python3 tools/build-yandex.py` и появляется в `dist/metrostroy-yandex.zip`.
В нём `index.html` в корне, шрифты лежат локально, подключён `/sdk.js` (LoadingAPI, GameplayAPI, пауза по событиям платформы и при сворачивании вкладки, полноэкранная реклама при перезапуске игры).
