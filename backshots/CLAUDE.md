# Backshots — памятка для Claude

Реалистичная королевская битва от первого лица в «закулисье» (Backrooms): жёлтые обои, ковёр, потолочная плитка,
гудящие и мигающие лампы. 15/20/25 бойцов (игрок + боты), последний выживший побеждает. Каждый матч — новый этаж
по зерну. Ориентир — Bodycam. Только ПК. three.js + postprocessing + Rapier, сборка esbuild. Замысел — `DESIGN.md`,
авторы — `CREDITS.md`. Сохранения `bs_`. Владелец говорит по-русски: отвечай просто. Ассеты: CC0, CC-BY, Mixamo.

## Где мы сейчас
- Этап 0: ассеты. Этап 1: прототип (этаж по зерну, боты, физика, две графики). Этап 2 (готов): оружие по везению,
  лут, броня, лечение, зона «свет гаснет», мини-карта и карта этажа (M), счётчик кадров, новые руки, спокойный темп.
- Дальше (этап 3): звук и атмосфера зоны (гул в темноте), ботам — бой за укрытием и выглядывание, упаковка
  для Яндекс Игр / CrazyGames; реалистичные модели жилета и шлема, если найдутся.

## Как работать
- Одна сессия — один этап; в начале читай этот файл, открывай только нужные файлы; в конце обнови его.
- Ветка — назначенная сессии; этап = PR в `main`, вливать можно самому. Первый запуск: `npm install` здесь.
- Логика (карта, бой, боты, матч) не трогает three.js — матч целиком идёт в node. Файлы до ~500 строк.
- Временные скрипты `tools/_что-то.mjs`, удалять после запуска.

## Команды
- Сборка: `npm run build` → `../docs/backshots` и `../packages/backshots*.zip`. https://anvar1103-master.github.io/100/backshots/
- Тест: `node tools/test.mjs [--dist]` (~10 мин): планы 5 зёрен, бот-матч с лутом и зоной в node (темп: 15+ живых
  через 30 с), бот-матч до победителя, стрельба/перезарядка, подбор и лечение, урон зоны, карта, физика, пауза,
  память, «Красивая», английский, внешние запросы.
- Баланс без графики: `node tools/balance.mjs [матчей] [бойцов]` (матч ≈ 2–4 с; печатает, сколько живы через
  30 с / 1 / 2 / 3 / 5 мин). План этажа картинкой: `node tools/map.mjs [зерно] [out.png]`.
- Скриншоты: `node tools/shot.mjs <папка> [medium|high] [зерно]` — меню, от 1-го лица, бот, прицел, бой, лут, край
  зоны, карта этажа. Руки с каждым стволом крупно: `node tools/vmshot.mjs <папка> [ak,pistol,…]` (быстро).
  Рендер программный: первый кадр ~70 с (шейдеры), потом 5–40 с на кадр. Не снимай на каждый шаг.

## Устройство src/js
- `level/gen.js` — этаж по зерну (ячейка 0,5 м, 220×220): зоны разбиением, двери, виды зон, ориентиры.
- `level/check.js` — щели, проходимость, высоты потолков, лампы, мокрые пятна, спавны, лут, предметы.
- `level/lights.js` — запекание света (`bakeLight`), `lightAt` (для ботов), `lightRGB` (для бойцов).
- `level/build.js` — меши: ковёр (мокрые пятна, отражения), обои, плинтус, плитка, лампы, EXIT; шейдеры уровня.
- `level/lamps.js` — живые прожекторы у ближних ламп (тени на «Красивой»), мигание, фонари, вспышки выстрелов.
- `level/reflect.js` — отражение в мокром полу (зеркальная камера, «Красивая»).
- `phys.js` — движение и лучи по сетке. `nav.js` — A* по ячейкам. `weapons.js` — цифры оружия, калибры, шансы при появлении.
- `fighter.js` — боец (два ствола, сумка патронов, броня, аптечки, наклон, фонарь). `combat.js` — выстрелы, хитбоксы, урон, броня.
- `match.js` — королевская битва (появление, лут, зона). `bots.js` — боты (темнота, слух, засады, лут, лечение, зона).
- `loot.js` — лут: раскладка, подбор, что нужно боту, выпадение с павших. `zone.js` — зона «свет гаснет».
- `lootview.js` — модели лута на полу. `minimap.js` — мини-карта и карта этажа.
- `engine.js` — рендерер, уровни графики, окружение для металла. `post.js` — свечение, тон, «нагрудная камера».
- `soldiers.js` — модели Mixamo: смешивание 8 направлений, наклоны корпуса, перезарядка, выбор смерти.
- `viewmodel.js` — руки от 1-го лица: предплечья той же модели в позе прицеливания едут вместе со стволом, левая
  кисть по IK (локоть вниз) на цевьё; перезарядка магазином и по патрону, помпа, затвор, лечение.
- `physics.js` — Rapier: стены, предметы, тряпичные куклы, толчки пулями. `props.js` — мебель Poly Haven.
- `gunmodels.js` — оружие (точки рукояти, мушки, дула). `fx.js` — кровь, пыль, гильзы. `audio.js` — звук.
- `player.js` — управление и камера. `hud.js` — интерфейс. `main.js` — загрузка, меню, цикл, `__bs`. `i18n.js` + `en.js`.

## Крючки `window.__bs` (страница с `?freeze`, время двигает тест)
`start({autopilot,count,diff,prep,seed})` (async), `sim(сек)`, `tick()`, `step(n, fire, aim)` (только игрок),
`aimAt(f, head)`, `settle(сек)`, `cam([x,y,z,tx,ty,tz])`, `newFloor(seed)`, `info()`, `bench()`, `lockLost()`, `G`, `PH`, `VMS`, `MODELS`,
`LOOT`, `Z`, `takeLoot(f, it)`, `losClear`, `bigMap(bool)`. В `start` ещё `gun` (оружие игрока) и `zone:false`.

## Ассеты (`src/assets`, готовит `tools/assets.mjs`, см. `CREDITS.md`)
- `node tools/assets.mjs mixamo <папка>` — персонажи Mixamo (FBX, кости переименованы без `mixamorig`, сетка ×0,5,
  текстуры 1024 webp) и движения из `tools/anims.json` в один `anims.glb` (у циклов убран снос бёдер).
- `guns <GunsExplosives/>`, `tex <backrooms/>` (нормали DirectX→OpenGL), `props <папка phm-*>`, `loot <папка phm-*>`
  (Poly Haven ammo_box, medical_box, medical_tape, wooden_military_crate), `sfx <папка>`.
- FBX читает three.js в headless Chromium (`tools/fbx2glb.html`), дальше gltf-transform + meshopt + sharp.
- Исходники Mixamo в открытый доступ не класть (условия Adobe): только ужатые модели в игре.

## Подводные камни
- Источники света не прятать (`visible`) — перекомпиляция всех материалов; только яркость.
- Свой `onBeforeCompile` + `customProgramCacheKey`: ключи склеивать, патч делать один раз (`userData.amb`).
- Кости Mixamo в сантиметрах под узлом с масштабом 0,01: из матриц брать позицию/поворот через decompose.
- Наличие щелей в одну клетку (0,5 м) ломает ботов: генератор их заливает, навигация их не считает проходом.
- Микшер не пишет кость, если значение не менялось: повороты поверх клипов откатывать перед кадром (`posed`).
- Эффект с `mainUv` нельзя ставить с эффектом-свёрткой: искажение линзы сделано внутри `BodycamEffect`.
- Металлическое оружие без окружения чёрное — `bakeEnv()` в `engine.js`.
- Темп боя задаёт то, сколько боты ходят: стоят — почти не встречаются. Вещи у самой стены недоступны (радиус
  бойца 0,34 м) — `loot.js` сдвигает их в комнату. Урон зоны приходит без `x/y/z` и `dir` (`o.zone`).
