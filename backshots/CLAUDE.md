# Backshots — памятка для Claude

Реалистичная королевская битва от первого лица в «закулисье» (Backrooms): жёлтые обои, мокрый ковёр, потолочная
плитка, гудящие лампы. 15–25 бойцов (игрок + боты), сужающаяся зона, лут в комнатах и тупиках. Каждый матч — новая
карта по случайному зерну. Ориентир по ощущению — Bodycam. Только ПК (мышь и клавиатура). three.js, сборка esbuild.
Замысел и цифры — `DESIGN.md`, авторы ассетов — `CREDITS.md`. Сохранения с префиксом `bs_`.
Владелец говорит по-русски: отвечай просто, без жаргона.

## Где мы сейчас
- Этап 0 (готов): подбор ассетов. Варианты, ссылки и отзывы — `DESIGN.md`, раздел «Ассеты». Ждём выбора владельца.
- Этап 1 (следующий): прототип — генератор этажа по зерну, бег, одно оружие, боты, автотест, скриншоты.
- Дальше: всё оружие и лут, зона, броня/аптечки, свет и пост-обработка, звук, меню, упаковка (Яндекс, CrazyGames).

## Как работать
- Одна сессия — один этап. В начале читай этот файл и открывай только нужные файлы. В конце этапа обнови его
  (файлы, крючки, подводные камни) и напиши владельцу, что делаем дальше.
- Ветка — та, что назначена сессии; каждый этап — отдельный PR в `main`, вливать можно самому.
- Первый запуск: `npm install` в этой папке. Образец устройства — `../microgang` (стрельба, кровь, хитмаркеры,
  звуки, боты). Генератор по зерну и проверка проходимости — образец `mushroom-brawl/src/js/maps.js` (`buildMaze`).
- Один файл — одна задача, до ~500 строк. Временные скрипты: `tools/_что-то.mjs`, удалять после запуска.
- Логика (карта, бой, боты, зона, лут) не трогает three.js — тогда матч целиком гоняется в node без графики.

## Команды (появятся на этапе 1)
- Сборка: `npm run build` → `../docs/backshots` (GitHub Pages) и `../packages/backshots*.zip` (веб, Яндекс,
  CrazyGames). Ссылка: https://anvar1103-master.github.io/100/backshots/
- Тест: `node tools/test.mjs [--dist]` — бот-матч до конца, стрельба игрока, карта по нескольким зёрнам
  проходима, английский, ни одного внешнего запроса.
- Баланс без графики (быстро, в node): `node tools/balance.mjs [матчей]` — убийства по оружию, дистанции, длина матча.
- Скриншоты: `node tools/shot.mjs <папка> "имя:x,y,z,tx,ty,tz"` — только чтобы проверить картинку: рендер
  в тестах программный (swiftshader), первый кадр компилирует шейдеры долго.

## Устройство src/js (план этапа 1; после этапа заменить на настоящий список)
- `rng.js` — зерно и случайные числа. `state.js` — общий `G`, `emit/on`.
- `level/gen.js` — этаж по зерну на сетке: залы, коридоры, залы с колоннами, двери, тупики, комнатки.
- `level/check.js` — проходимость (заливка + пробить стену), ориентиры, точки появления, места лута.
- `level/lights.js` — лампы: горят / мигают / погасли; карта освещённости (для ботов и для картинки).
- `level/build.js` — меши из сетки (стены, пол, потолок, плинтусы, лампы), инстансы.
- `phys.js` — столкновения с сеткой и лучи. `nav.js` — сетка и A*.
- `weapons.js` — цифры оружия. `combat.js` — выстрел лучом, урон по расстоянию, хитбоксы, броня.
- `fighter.js` — боец (игрок и бот по одним правилам). `loot.js` — лут и подбор. `zone.js` — зона.
- `bots.js` — мозги ботов. `match.js` — ход матча (работает и в node).
- `engine.js` — рендерер, уровни графики. `post.js` — шум камеры, виньетка, свечение, тон.
- `soldiers.js` — модели солдат и анимации. `gunmodels.js`, `viewmodel.js` — оружие и руки от 1-го лица.
- `player.js` — управление и камера. `hud.js`, `fx.js` (кровь, гильзы, искры), `audio.js` (выстрелы, эхо, гул).
- `main.js` — загрузка, меню, цикл, `__bs`. `i18n.js` + `en.js` — новый русский текст добавляй в `en.js`.

## Крючки `window.__bs` (план)
`start({seed,count,autopilot,weapon})`, `sim(сек)` (симуляция без рисования), `tick()` (кадр), `cam([x,y,z,tx,ty,tz])`,
`freeze`, `info()`, `bench()`, `G`. Страница с `?freeze` — время двигает тест.

## Ассеты
- Только CC0, в сборке никаких внешних запросов. Персонажей, оружие и крупные предметы — готовыми моделями
  (через помощника `asset-scout`), в коде только простое: лампы-панели, частицы, эффекты.
- Готовить один раз скриптами (`@gltf-transform` + `sharp`: уменьшить текстуры, сжать, склеить в один файл),
  как делать — записать сюда.
- Превью для выбора делались своим стендом: three.js в headless Chromium отрисовывает модели и тестовый коридор
  с текстурами (тот же способ годится для проверки новых ассетов).

## Подводные камни
- (из microgang) Микшер three.js пишет кость, только когда значение изменилось: повороты поверх клипов перед
  каждым кадром откатывать, иначе копятся.
- (из microgang) Фон сцены затирает кадр при втором `render()` — для прохода рук с оружием фон убирать.
- Шейдеры без NaN: не `smoothstep` с равными краями, `pow` с обрезанным основанием.
