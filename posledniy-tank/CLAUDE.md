# «Последний танк» — памятка для Claude

Отдельная игра-ответвление от Brawl Green (репозиторий `anvar1103-master/mushroom-brawl`): тот же лес, лабиринт,
боты и режим «Последний гриб» (королевская битва на 10), только вместо героев — 5 танков. Режима «Споры» и
футбола в меню нет (код остался, но не используется). Основную Brawl Green не трогает: своя папка, свой префикс
сохранений `pt_` (у Brawl Green `bg_`, обе игры живут на одном домене GitHub Pages). Владелец говорит по-русски.

## Как работать
- Ветка `claude/dreamy-euler-4ve6df` в репозитории `100`, PR в `main`, вливать можно самому. Первый запуск: `npm install`.
- Сборка: `npm run build` → `../docs/posledniy-tank` (GitHub Pages) и `../packages/posledniy-tank*.zip`.
  Ссылка: https://anvar1103-master.github.io/100/posledniy-tank/
- Тест: `node tools/test.mjs [--dist]` — по одной королевской битве за каждый танк, английский, нет внешних запросов.
  Баланс: `node tools/balance.mjs [N] [--dist]`, телефоны: `node tools/ui-check.mjs <папка> [--dist]` (порт 8125).

## Танки
| id (как в Brawl Green) | Танк | Модель (`src/assets/tanks`) |
|---|---|---|
| shroom | Картечник, тяжёлый, картечь | heavy_tank.glb |
| beetle | Мортира, навесные мины | artillery_tank.glb |
| wasp | Дальнобой, снайпер с прицелом | sniper_tank.glb |
| roly | Рикошет, рикошетящие снаряды | light_tank.glb |
| hopper | Стрекот, очереди | rapid_tank.glb |

- `tankmodels.js` грузит GLB, режет на корпус / башню / ствол (по именам узлов Hull, Turret, Barrel), оставляет родные
  военные текстуры (у моделей без текстур — цвета из `paint`), подгоняет размер, находит дуло; ленты гусениц (материал
  Tread/Track) получают прокрутку текстуры. `icons.js` снимает модели в картинки для меню и таблиц.
- `tanks.js` — формат частей и запасные танки из фигур (если модели не загрузились).
- `anim.js` — реалистичные анимации (без глаз и мультяшных прыжков): корпус поворачивает по ходу и сдаёт задом,
  приседает на подвеске, гусеницы катятся, башня следит за прицелом, откат ствола и дым из дула, пыль и выхлоп,
  при появлении танк выезжает из кустов, подбитый — башню срывает, корпус чернеет и горит. Материал — `tankMaterial` в rig.js.
- Характеристики и тексты — `heroes.js`, английский — `en.js`.
